# Connect Quest

> Gamified university community platform with AI-powered challenge verification.

[🚀 Live Demo](https://main.dx8ly1r352j1q.amplifyapp.com/)

## 📖 Overview

Connect Quest is a full-stack web application that helps university students connect with their campus community through challenges, daily activities, points, and streaks.

Students can complete community-focused challenges and submit text or photo evidence, which is evaluated against the challenge requirements using a multimodal AI pipeline.

## ✨ Features

* 🎯 **Community Challenges** — Complete challenges designed to encourage campus engagement
* 📅 **Daily Activities** — Participate in daily activities to earn points and maintain streaks
* 🤖 **AI-Powered Verification** — Automatically evaluates text and photo submissions against challenge requirements
* 🔥 **Points & Streaks** — Earn points and maintain streaks as challenges are completed
* 📊 **Progress Tracking** — Persist and track challenge completion and progress

## 🛠️ Tech Stack

* **Frontend:** React
* **Backend:** Node.js
* **AI:** AWS Bedrock
* **Cloud:** AWS Lambda, API Gateway, S3, DynamoDB, Cognito, Amplify

## 🚀 Getting Started

### Prerequisites

* Node.js
* AWS account
* AWS Bedrock access

### Installation

1. Clone the repository:

```bash
git clone https://github.com/amishi-arora/Connect-Quest.git
cd Connect-Quest
```

2. Install dependencies:
```bash 
cd frontend
npm install
```
```bash
cd ../backend
npm install
```

3. Configure the required environment variables and AWS resources

4. Start the backend 

```bash
cd backend
npm start
```

5. Start the frontend
```bash
cd frontend
npm start
```
